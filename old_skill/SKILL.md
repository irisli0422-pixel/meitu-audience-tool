# 美图定制人群包生成器

## 概述

为品牌方生成标准化的美图定制人群包圈选规则Excel文件。人群包是美图广告投放的核心定向工具，通过影像识别、LBS、原生需求、社区互动、广告点击行为等六大维度圈选目标受众。

## 工作流程

### 第一步：收集品牌信息

向用户确认以下信息（如未提供则主动询问）：
1. **品牌名称**（中英文）
2. **主推产品/产品线**（具体到单品或系列）
3. **合作内容**（联名IP、主推场景、核心卖点等）
4. **竞品品牌**（如未提供，根据品类自行补充）
5. **目标人群**（年龄/性别/消费力偏向，如未提供则根据品牌特性判断）

### 第二步：设计人群包结构

参考 `references/meitu_audience_format.md` 了解标准格式，参考 `references/case_studies.md` 了解已交付案例。

人群包标准组合：
- **必选**：本竞品人群包 + 种子人群包（2个）
- **品牌定制**：根据品牌特性设计6-8个人群包
- **总计**：通常10个人群包，约45-55个子标签

设计原则：
1. 每个人群包包含4-6个子标签
2. 每个人群包至少包含「影像识别」+ 1-2个其他维度
3. 子标签量级预估范围：120w-1000w（种子人群包50w-85w）
4. 竞品名单需覆盖国际+国产品牌
5. 圈选规则需具体到可执行的关键词/场景/品牌名

### 第三步：生成Excel文件

使用 `scripts/generate_audience_template.py` 模板脚本生成Excel：

1. 复制模板脚本到工作目录
2. 修改以下配置区变量：
   - `BRAND_NAME` / `BRAND_NAME_EN`：品牌名称
   - `COLOR_TITLE` / `COLOR_SECTION` / `COLOR_HEADER`：品牌配色
   - `DATA_NOTES`：数据说明5条
   - `SUMMARY_TEXT`：人群包汇总公式
   - `BASIC_TARGETING`：基础人群定向4行
   - `SEGMENTS`：人群包数据列表（核心）
   - `SEGMENT_COLORS`：各人群包行背景色
   - `REMARKS`：备注7-8条
3. 运行脚本生成Excel

### 第四步：验证输出

生成后读取Excel验证：
- 总行数是否符合预期（通常75-90行）
- 所有人群包名称、子标签、圈选规则、量级是否完整
- 合并单元格是否正确
- 配色是否统一

## 六大圈选维度

设计子标签时，从以下维度中选择：

### 1. 影像识别（核心，每个人群包必含）
识别用户图片中的品牌LOGO、场景、物品等元素。
- 场景格式：`影像识别用户近180天内图片中高频出现XXX场景：[元素列举]`
- 品牌格式：`近180天内通过影像识别侦察到【品牌A、品牌B】品牌形象的用户`

### 2. LBS场景识别
基于地理位置匹配线下场所POI。
- 格式：`近180天内通过LBS及影像识别侦察到【场所A、场所B】的用户，频次≥N次`

### 3. 原生需求
用户在美图秀秀中主动使用的功能/配方/滤镜。
- 格式：`近180天内在美图秀秀产品产生原生需求【关键词A、关键词B】配方/滤镜/贴纸的用户`

### 4. 社区互动
用户在美图社区发布或互动的话题。
- 格式：`近180天内在美图社区中发布或互动【话题A、话题B】相关话题及图片的用户`

### 5. 广告点击行为
用户点击广告的行为数据。
- 格式：`在美图系平台的广告点击行为数据判断出用户对相关广告感兴趣，广告点击兴趣=关键词A/关键词B，频次=30天`

### 6. 种子人群（仅种子人群包）
- 历史互动：`2024-2025年度在美图秀秀APP点击过XX品牌广告...的人群（去重种子人群包）`
- 品牌搜索：`近365天内在美图系平台搜索过XX/XX等关键词的用户`

## 常见人群包类型

根据品牌品类选择合适的定制人群包：

| 品类 | 推荐人群包 |
|------|-----------|
| 食品/乳制品 | 烘焙兴趣、品类场景（如奶茶/酥皮甜点）、母婴家庭、健康生活、品质烹饪、高净值、西式生活方式 |
| 零食/巧克力 | 品类场景（如下午茶/晚间休闲）、母婴亲子、零食爱好者、社交分享开箱、年轻潮流 |
| 运动鞋履/服饰 | 运动健身、潮流穿搭、舒适通勤、亲子户外、健康生活、City Walk、年轻潮流 |
| IP联名 | IP粉丝、潮玩收藏、影视爱好者、Cosplay/同人、Z世代潮流、社交分享 |
| 赛车/汽车 | 赛车运动爱好者、车队粉丝、车手粉丝、CP粉丝、超跑生活方式、潮流色彩 |
| 美妆/护肤 | 美妆爱好者、护肤人群、高净值、Z世代潮流、社交分享种草 |

## 注意事项

1. 人群包量级为预估，实际以系统圈选为准
2. 时间窗口统一使用「近180天」（广告点击可灵活用30/90/180/365天）
3. 竞品品牌需同时覆盖国际+国产
4. 品牌配色从品牌VI提取，标题深色→板块中色→表头亮色递进
5. 各人群包行使用不同浅色背景交替，便于阅读
6. 输出后务必验证Excel内容完整性
