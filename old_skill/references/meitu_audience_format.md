# 美图人群包标准格式参考

## 一、Excel 文件整体结构

每个人群包 Excel 包含 **4大板块**，按顺序排列：

1. **标题行** — 合并A:D列，品牌色背景+白字
2. **数据说明** — 合并A:D列，列出5条说明
3. **人群包汇总** — 合并A:D列，1行公式文本
4. **基础人群定向** — 4行（性别/年龄/兴趣/消费），A列合并
5. **定制人群包圈选规则** — 核心部分，每个子标签1行
6. **备注** — 合并A:D列，7-8条说明

## 二、列定义（A/B/C/D）

| 列 | 列名 | 宽度 | 说明 |
|----|------|------|------|
| A | 人群包 | 20 | 人群包名称（同组首行显示，其余合并） |
| B | 人群标签 | 26 | 子标签名称 |
| C | 秀秀单标签逻辑之一 | 68 | 圈选规则详细描述 |
| D | 人群包量级 | 14 | 预估量级（如 380w） |

## 三、六大圈选维度（子标签类型）

每个人群包通常包含以下维度的组合：

### 1. 影像识别（最核心）
- 通过美图AI图像识别用户上传/编辑图片中的品牌LOGO、场景、物品等元素
- 格式：`影像识别用户近180天内图片中高频出现XXX场景：[具体元素列举]`
- 品牌识别格式：`近180天内通过影像识别侦察到【品牌A、品牌B、品牌C】品牌形象的用户`

### 2. LBS场景识别
- 基于用户打开APP时的地理位置，匹配线下消费场所POI
- 格式：`近180天内通过LBS及影像识别侦察到【场所A、场所B、场所C】的用户，频次≥N次`

### 3. 原生需求
- 用户在美图秀秀中主动使用的功能/配方/滤镜/贴纸
- 格式：`近180天内在美图秀秀产品产生原生需求【关键词A、关键词B、关键词C】配方/滤镜/贴纸的用户`

### 4. 社区互动
- 用户在美图社区发布或互动的话题
- 格式：`近180天内在美图社区中发布或互动【话题A、话题B、话题C】相关话题及图片的用户`

### 5. 广告点击行为
- 用户在美图系平台点击广告的行为数据
- 格式：`在美图系平台的广告点击行为数据判断出用户对相关广告感兴趣，广告点击兴趣=关键词A/关键词B/关键词C，频次=30天/90天/180天/365天`

### 6. 种子人群
- 历史互动+品牌搜索
- 格式1：`2024-2025年度在美图秀秀APP点击过XX品牌广告、参与过XX话题互动、使用过XX联名配方/贴纸/滤镜的人群（去重种子人群包）`
- 格式2：`近365天内在美图系平台搜索过XX/XX/XX等关键词的用户`

## 四、标准人群包组合（10个）

### 必选人群包（所有品牌通用）
1. **本竞品人群包** — 品牌自身+竞品品牌识别、广告点击、门店LBS
2. **种子人群包** — 历史互动+品牌搜索

### 品牌定制人群包（根据品牌特性选择6-8个）
常见类型：
- 运动健身人群包（运动品牌）
- 潮流穿搭人群包（服饰/鞋履品牌）
- 烘焙兴趣人群包（食品/乳制品品牌）
- 母婴亲子人群包（儿童/家庭产品）
- 健康生活人群包（健康/食品品牌）
- 高净值人群包（高端品牌）
- 西式生活方式人群包（进口/西式品牌）
- 影视/IP粉丝人群包（IP联名品牌）
- 社交分享/种草人群包（消费品品牌）
- 品类场景人群包（如奶茶人群包、酥皮甜点人群包等）

## 五、基础定向标准

| 维度 | 标准内容 |
|------|----------|
| 性别 | 女/男（注明偏向及原因），整体全覆盖 |
| 年龄 | 核心人群年龄段（如18-35岁/25-45岁/16-35岁） |
| 兴趣爱好 | 安装应用偏好 + 社区兴趣偏好（与品牌相关） |
| 消费力 | 中等及以上/中高消费（月收入区间） |

## 六、数据说明标准（5条）

1. 整体逻辑说明
2. 涉及APP：美图系场景（美图秀秀、美颜相机等）
3. 时间范围：近6个月（180天）
4. 品牌背景信息（产品线、定位、核心卖点）
5. 本次核心场景说明

## 七、备注标准（7-8条）

1. 量级为预估，以系统最终圈选为准
2. 并集∪/交集∩逻辑说明
3. 影像识别技术说明
4. LBS场景识别说明
5. 原生需求说明
6. 品牌核心信息（产品线/卖点/定位）
7. 核心人群优先级说明（高转化/高复购/高传播）

## 八、样式规范

### 字体
- 标题：微软雅黑 16pt 粗体 白字
- 板块标题：微软雅黑 12pt 粗体 白字
- 表头：微软雅黑 10pt 粗体 白字
- 内容：微软雅黑 10pt #333333
- 备注：微软雅黑 9pt #666666

### 配色
- 标题行：品牌主色（深色）
- 板块标题：品牌主色（中色）
- 表头：品牌主色（亮色）
- 基础定向：浅色背景
- 各人群包：交替浅色背景（每个人群包一种浅色）
- 边框：细线 #B0B0B0

### 行高
- 标题行：40
- 板块标题：28
- 表头：28
- 数据说明/备注：20
- 基础定向：24-50（根据内容）
- 圈选规则行：36-90（根据内容长度自动计算）
